แพ็กนี้คืนไฟล์เกม V205 ที่ผู้ใช้ส่งมาโดยตรง โดยไม่แก้ script.js และไม่แก้ index.html
เพิ่มเฉพาะไฟล์ตั้งค่า Supabase และ SQL ที่ไม่ถูกโหลดโดยเกม จึงไม่ทำให้ปุ่มล็อกอินหรือระบบเล่นเกมเปลี่ยน

ไฟล์สำคัญ:
- script.js = ของ V205 เดิม
- index.html = ของ V205 เดิม
- style.css = ของ V205 เดิม
- supabase-config.js = ค่าเชื่อมต่อ Supabase ที่เตรียมไว้
- supabase_online_setup.sql = ตารางเซฟออนไลน์ที่รันแล้ว

ใช้แพ็กนี้เพื่อยืนยันว่าตัวเกมฐานยังทำงานเหมือน V205 เดิมก่อนเชื่อมออนไลน์ขั้นถัดไป
